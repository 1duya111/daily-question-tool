Ask Someting --
Record your instant mood by answering random fun daily questions,with a history log to review your past thoughts.Run with ' python main.py'
自动化测试模块 (test_web.py)：
本项目包含基于 Selenium 的 Web 自动化测试脚本。通过 Edge 浏览器驱动，实现了自动打开网页、定位输入框、输入关键词、按回车搜索，并利用 assert 断言验证搜索结果标题。代码中使用了 WebDriverWait 显式等待机制，处理页面加载延迟问题。
